## ▶️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/shekinapilla4809/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser.

No build tools or package installation are required for this standalone HTML portfolio.

---

## 🌍 Deploy With GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
6. Wait for GitHub Pages to publish the site.

Your published URL will be shown in the repository's Pages settings.
